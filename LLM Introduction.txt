What is an LLM?

A Large Language Model (LLM) is a neural network, almost always a transformer, trained on very large amounts of text and code to predict the next token in a sequence. By doing this at massive scale (billions of parameters, trillions of training tokens), it learns grammar, facts, reasoning patterns and programming. It can then summarize, translate, answer questions and write code from a plain-language prompt.

In one line: an LLM is a very large, pre-trained next-token predictor that can be steered with instructions to do many language and code tasks.

1. Foundations

NLP basics, and machine learning and neural network basics (training, loss, gradient descent)
Probability and linear algebra essentials (vectors, matrices, softmax)

2. Text representation

Tokenization (BPE, WordPiece) and vocabulary
Embeddings (token, positional, sentence) and vector similarity

3. Transformer architecture

Self-attention, Q/K/V, multi-head attention, softmax
Feed-forward layers, residual connections, layer normalization
Encoder-only, decoder-only and encoder-decoder models (BERT, GPT, T5)
LM head and next-token generation

4. Training an LLM

Pre-training (next-token prediction on large corpora)
Fine-tuning and instruction tuning
Alignment (RLHF, preference optimization)
Scaling laws, parameters and compute

5. Using an LLM

Prompt engineering (zero-shot, few-shot, chain-of-thought)
Generation settings: temperature, top-k, top-p, max tokens
Context window and token limits
Hallucination, bias and other limitations

6. Applied LLM techniques (most relevant to your dissertation)

RAG (retrieval-augmented generation), vector databases and semantic search
Agents: tool use / function calling, planning, memory, ReAct and reflection
Multi-agent systems: orchestration and agent communication (LangChain, LangGraph, AutoGen)
LLMs for code: code generation, code review, and benchmarks like HumanEval and SWE-bench

7. Evaluation and safety

Metrics (pass@k, accuracy, precision and recall, human evaluation)
Security risks: prompt injection, data leakage, insecure generated code
Responsible AI, auditability and governance (key for banking)

8. Engineering and deployment

APIs, cost and latency, caching
Open-source versus proprietary models (Llama, GPT, Claude)
